# Synora next phase — product brief (synthetic draft)

**Status:** Working draft for review  
**Project:** Synora project-intelligence workspace

## Goal

Help teams turn project conversations and documents into traceable knowledge and a visual Project Atlas.

## Phase scope

The next phase supports Google Meet transcripts, WhatsApp messages, and manual document or text uploads. Excalidraw is the visual output. Canvas edits are not ingested as evidence.

Synora uses one shared agent and one shared memory engine. Project boundaries constrain what context the agent can use.

## Expected user experience

The user connects a source, reviews project routing when it is uncertain, and sees source-linked decisions, requirements, and actions in the project workspace. The Atlas is generated from approved project context.

## Timing assumption

The team is planning a limited pilot for **December 7, 2026**. This date is a planning assumption, not a public launch commitment.
