# Synora integration scope — connector discussion (synthetic draft)

**Status:** Connector planning note

## Proposed for the next phase

- Google Meet completed transcripts, including speaker and timestamp references.
- WhatsApp messages through the approved bridge.
- Manual text and document uploads.
- Excalidraw Project Atlas as a generated, read-only view.

## Not included in the first pilot

- Direct ingestion of Excalidraw scene edits.
- Automatically routing ambiguous evidence into a project.
- Treating generated summaries as source evidence.

For project-state changes, the connector should create a reviewable proposal when a new item replaces an already approved decision or requirement. A member approval is needed before the replacement becomes the active state.

The pilot should not be scheduled until connector access, data retention, and project membership checks have named owners. No date is approved in this note.
