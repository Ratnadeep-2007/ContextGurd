Follow the action

  1. frontend/src/components/Report.tsx, FindingDetail.save: the form sends an answer, owner, action, and current case version. It does not rewrite source text.
  2. backend/app/main.py, resolve: the API validates the current case, appends a fingerprint-bound resolution event, saves to SQLite through store.py, and starts a full recheck.
  3. backend/app/workflow.py, verify: only a matching current-input answer overlays the selected finding's status. The browser polls the actual run and renders the updated report.

To change this, start here

  • Colors, spacing, readable guide text: frontend/src/styles.css.
  • Sample sources and deliberately planted issues: backend/app/sample.py.
  • Provider models and bounded retry/fallback: backend/app/providers.py.
  • Which quotes may become findings: backend/app/workflow.py, verify.
  • Regression evidence for saved answers: backend/tests/test_api.py, test_resolution_persistence_recheck_and_undo.

A practice to reuse

Keep evidence immutable and user choices separately attributable. The whitespace-quote regression test exposed that an empty normalized quotation can match any source text. The verifier now rejects it. A syntactically valid model response is not enough: specify and test the evidence boundary.

Run again

Install dependencies as documented in README.md, build with npm run build inside frontend/, then run python scripts/serve.py from the root. Open localhost:8017.
