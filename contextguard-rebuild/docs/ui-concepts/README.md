## Prompt brief and constraints

Generate a high-fidelity desktop ContextGuard Project Reviews screen using fictional Synora data. Show project selection, five consolidated issue families, opposing date passages, an accountable owner selector before the contextual answer selector, and clear record/export actions. Compare the same workflow across three palettes. Use rectangular components, solid CSS colors, readable typography, clear spacing, source provenance and short functional labels. Exclude gradients, rounded components, decorative shadows, glows, AI slogans, invented readiness scores and charts.

Palette prompts: Graphite & Cobalt uses charcoal #20252D, paper #F4F5F7 and cobalt #2549A2. Warm Paper & Olive uses ivory #F5F2EA, bone #EAE6DA, ink #292C27 and olive #4D5940. Midnight & Steel uses charcoal-blue #141A21, sidebar #10151B, surfaces #1D2631 and ice-blue #A0BFDD. Final implementation must use literal flat fills; these generated previews establish a visual direction rather than a browser-verified UI.

Built-in imagegen was used, without a CLI/API-key fallback. Original generated images remain in Codex generated_images; these copies are local project deliverables. This does not claim the fictional review or any live source/model test passed.
